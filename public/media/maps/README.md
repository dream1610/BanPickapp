# Map media naming

## Minimap

Put one minimap PNG per map in `minimaps/`:

```text
summit.png
corrode.png
abyss.png
sunset.png
lotus.png
pearl.png
fracture.png
breeze.png
icebox.png
ascent.png
split.png
haven.png
bind.png
```

## Gallery

Create one folder per map in `gallery/`, with up to five JPG images:

```text
gallery/ascent/01.jpg
gallery/ascent/02.jpg
gallery/ascent/03.jpg
gallery/ascent/04.jpg
gallery/ascent/05.jpg
```

Use the same pattern for every map, for example `gallery/bind/01.jpg` or `gallery/summit/01.jpg`.

The gallery uses the official map cover as a visual fallback when a local gallery image has not yet been added.
